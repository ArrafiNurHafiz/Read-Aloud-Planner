Accessibility & Screen Reader Guide

Read Aloud Planner is engineered from the ground up for individuals with visual impairments, low vision, severe dyslexia, and keyboard-only users without any reliance on a mouse.

Keyboard Shortcuts

Key Action
V Activate Speech Recognition to add tasks naturally by voice without typing.
S Start or stop sequential linear speech reading of the entire day's schedule.
D Toggle completion status of the active or currently focused task.
N Open dialog modal to add a new task manually.
Esc Close dialog modals or exit Focus Mode.
Tab / Shift + Tab Move keyboard focus linearly and predictably between interactive controls.

Two-Tap Blind Assist Mode (TalkBack & VoiceOver Style)

Designed specifically to assist visually impaired individuals on touchscreens and mouse devices without accidental clicks:

  • Single Tap / Click: Speaks the name of the button and its function aloud without executing it.
  • Double Tap / Click: Executes the selected feature or action immediately.
  • This assistance mode is active by default and can be toggled at any time using the "Double Tap" button in the navigation bar.

Multilingual Support

Read Aloud Planner seamlessly supports both English and Bahasa Indonesia. Switching the language dropdown instantly translates all user interface labels, switches linear speech sentences, re-tunes speech recognition, and updates accessibility voice announcements.

Screen Reader Compatibility

The application is fully audited and compatible with modern screen readers including NVDA, JAWS, VoiceOver (macOS / iOS), and TalkBack (Android).

  • Semantic Landmarks: All layout areas utilize semantic HTML5 elements (Header, Main, Nav, Section, Dialog) to allow instant landmark jumping.
  • Linear Time Sentences: Replaces visual grid matrices with natural, complete sentences (e.g., "Monday, 08:00, Database Architecture Lecture, 2 hours, Room 301. Completed.").
  • ARIA Live Announcements: Dynamic schedule mutations (task added, marked done, or deleted) are announced via polite live regions without interrupting current user speech.
  • Textual Caption Fallback: Visual caption box displays all spoken speech synchronously in real time.

WCAG 2.2 Level AA Compliance

Read Aloud Planner satisfies Web Content Accessibility Guidelines (WCAG) 2.2 Level AA requirements:

  • Contrast Ratio (Criteria 1.4.3 & 1.4.11): Text contrast ratio is ≥ 4.5:1, and user interface controls are ≥ 3:1. High Contrast theme provides pure black and luminous amber styling.
  • Focus Rings (Criteria 2.4.7 & 2.4.11): Interactive elements feature a solid 3px outline with a 3px offset.
  • Target Size (Criterion 2.5.8): All buttons and touch targets meet the minimum 44x44px boundary.
  • Responsive Typography: Fluid text scales up to 200% without breaking page layout.
