Panduan Aksesibilitas & Pembaca Layar

Read Aloud Planner dirancang dari awal untuk penyandang disabilitas netra, penglihatan rendah (low vision), dan pengguna keyboard murni tanpa ketergantungan pada tetikus (mouse).

Panduan Pembaca Layar (Screen Reader)

Aplikasi ini kompatibel secara penuh dengan pembaca layar modern seperti NVDA, JAWS, VoiceOver (macOS / iOS), dan TalkBack (Android).

  • Landmark Semantik: Seluruh area aplikasi diidentifikasi menggunakan elemen semantik HTML5 standar (Header, Main, Nav, Section, Dialog) sehingga Anda dapat melompat antar bagian menggunakan tombol pintasan pembaca layar Anda.
  • Format Kalimat Linear: Setiap kegiatan dirangkum dalam kalimat waktu lengkap yang teratur (contoh: "Senin, 08.00, Kuliah Basis Data, 2 jam, ruang 301. ✓ Selesai"), menghindari kebingungan navigasi sel kisi kalender visual.
  • Pemberitahuan Dinamis (ARIA Live): Pembaruan status (seperti kegiatan baru ditambahkan, dihapus, atau ditandai selesai) diumumkan secara sopan (polite live region) agar tidak memotong ucapan screen reader Anda saat sedang mengetik.
  • Teks Takarir Suara (Caption Fallback): Jika browser tidak mendukung Web Speech API atau suara dimatikan, teks pembacaan tetap ditampilkan di area status takarir visual.

Komitmen Standar WCAG 2.2 Level AA

Read Aloud Planner memenuhi standar Web Content Accessibility Guidelines (WCAG) 2.2 Level AA:

  • Rasio Kontras Warna (Kriteria 1.4.3 & 1.4.11): Rasio kontras teks biasa minimal 4.5:1 terhadap latar belakang. Komponen antarmuka pengguna memiliki rasio kontras minimal 3:1. Tersedia pula Mode Kontras Tinggi untuk tampilan hitam-kuning monokrom.
  • Indikator Fokus Visual (Kriteria 2.4.7 & 2.4.11): Elemen interaktif yang menerima fokus keyboard ditandai dengan garis batas solid tebal 3 piksel dengan jarak offset 3 piksel.
  • Ukuran Target Sentuh (Kriteria 2.5.8): Seluruh tombol, bidang masukan formulir, dan tautan memiliki dimensi fisik minimal 44x44 piksel.
  • Tipografi Fleksibel: Ukuran font dapat diperbesar hingga 200% tanpa kehilangan konten atau fungsionalitas aplikasi.
